\chapter{Conclusion}

Ce projet a permis de mettre en œuvre un modèle de machine learning capable de prédire les chances d'admission des candidats dans les universités, à partir de différentes informations académiques et personnelles. 

Plusieurs étapes ont été franchies avec succès : 
\begin{itemize}
    \item \textbf{Préparation des données} : nettoyage et sélection des colonnes pertinentes.
    \item \textbf{Modélisation} : comparaison de plusieurs modèles classiques (SVC, Random Forest, Decision Tree, Logistic Regression, K-Nearest Neighbors) pour identifier celui offrant les meilleures performances.
    \item \textbf{Évaluation} : analyse des métriques de classification (accuracy, précision, recall, F1-score) et visualisation des courbes d'apprentissage.
    \item \textbf{Déploiement local} : implémentation d'un script interactif permettant à l'utilisateur de tester le modèle en fournissant ses propres données.
\end{itemize}

Les résultats ont montré que le modèle de \textbf{Logistic Regression} offrait un compromis intéressant entre précision et capacité d'apprentissage, étant capable de généraliser correctement sur de nouvelles données. Comparé aux autres modèles qui semblaient mémoriser les jeux de données d'entraînement, le modèle logistic a été le seul à réellement apprendre les relations entre les variables.

Enfin, ce projet constitue une base solide pour un futur déploiement plus avancé, pouvant inclure une interface web ou une API, afin de rendre le modèle accessible à un plus grand nombre d'utilisateurs. 

\bigskip
Le travail effectué illustre également l'importance de la préparation des données et de l'évaluation rigoureuse des modèles, étapes essentielles dans tout projet de machine learning.
